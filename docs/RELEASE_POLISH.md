# Запуск и полировка · 20.10.2026

Новая инструкция пользователя разрешает публикацию вымышленного набора задания, кроме потенциально настоящих телефонов. Это заменяет прежнее ограничение на публикацию имён/расшифровок в AUDIT/QA и ранних записях журнала.

## Что изменено

- Публичные API CRM и звонков показывают оригинальные результаты. Телефоны заменены стабильными метками после вычислений. Исходники и числовые правила не изменены. Маскированный экспорт не предлагается как исходник для повторного анализа.
- Памятка отделена от SaaS: редакционная типографика, схема трёх механизмов, четыре пояснения к структуре промпта. Ситуации — только бизнес вчера/сегодня и свежие цены из лекции. Новых примеров промптов нет. HTML автономен; PDF одна A4. Фактические исправления и ограничения первоисточников сохранены.
- По новой инструкции платный worker исключён. Подготовлен Vercel webhook с Redis-блокировками, локальный polling сохранён. Бесплатный тариф Redis и лимиты Hobby требуют проверки в панели; документация недоступна через сетевой шлюз. Подробности: FREE_DEPLOY.md.
- Браузерные тесты используют изолированные порты 5174/8001, чтобы не тестировать старый запущенный API.

## Внешние ограничения

В среде нет безопасно установленного Telegram токена, разрешённого ID, доступа Vercel и Redis. Переданный в сообщении токен не переносился в команды, файлы, историю или логи. Инструмент настройки среды объявляет требования к секретам, но не сохраняет значения. Публичный URL и реальный Telegram E2E пока отсутствуют; локальные проверки их не заменяют. Требуется ввод в защищённом UI и действие разрешённого Telegram-пользователя. Архив не пересобирался.
