# Проверка утверждений лекции

Проверено 20 октября 2026. Это проверка документации, не выполнение платного API-вызова.

| Утверждение | Вердикт и основание |
|---|---|
| «Контекстное окно — сколько чат помнит между разными чатами» | Неверное отождествление. Контекст ограничивает доступные модели токены, не гарантирует межчатовую память. В официальном контракте Messages API прошлые ходы передаются явно в `messages`. Это свидетельство об API, а не описание всех функций интерфейса Claude. |
| «Если вчера рассказал Claude про бизнес, сегодня он уже знает» | Гарантия не обоснована. Возможности памяти конкретного аккаунта не проверены. Не переносим свойства контекстного окна на историю других чатов. |
| «У Claude вообще нет доступа к интернету» | Опровергнуто официальным SDK: есть `web_search`, его тип, параметры и пример подключения к запросу. Не означает, что поиск доступен и включён в каждом продукте/аккаунте. |
| «Свежие цены не найдёт никогда» | Категоричность неверна из-за наличия поиска. Проверять дату и источник — наш методический вывод, не цитата производителя. |
| «Роль, задача, формат, пример» | Сохранён полезный каркас из лекции. Это рекомендация, не доказанный необходимый формат любого запроса. Новые примеры не добавлялись. |

Прочитанные первоисточники — официальный репозиторий `anthropics/anthropic-sdk-python`, commit `bcd55fe1d3f0f1240765f8cef04295b67337f55a`:

- [Пример web search](https://github.com/anthropics/anthropic-sdk-python/blob/bcd55fe1d3f0f1240765f8cef04295b67337f55a/examples/web_search.py), подключение инструмента в `tools`, строки 6–18.
- [Контракт инструмента](https://github.com/anthropics/anthropic-sdk-python/blob/bcd55fe1d3f0f1240765f8cef04295b67337f55a/src/anthropic/types/web_search_tool_20250305_param.py), name/type/max_uses/allowed_domains.
- [Messages API](https://github.com/anthropics/anthropic-sdk-python/blob/bcd55fe1d3f0f1240765f8cef04295b67337f55a/src/anthropic/types/message_create_params.py), описание `messages`: “you specify the prior conversational turns with the messages parameter”.
- [Предел контекста как причина остановки](https://github.com/anthropics/anthropic-sdk-python/blob/bcd55fe1d3f0f1240765f8cef04295b67337f55a/src/anthropic/types/message.py), `model_context_window_exceeded`.

Их содержимое не цитируется как прочитанное. Затем успешно прочитаны указанные исходники через доступный GitHub. Чужой код не запускался, SDK не устанавливался, API-ключ не использовался.

Памятка не обещает актуальные тарифы, лимиты или функциональность определённой версии модели. Только примерные ситуации из исходной лекции: вчерашний рассказ о бизнесе, свежие цены и каркас промпта.
