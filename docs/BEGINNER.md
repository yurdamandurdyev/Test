# Задача 2 — инструкция без опыта программирования

1. Установите Python 3.12 или новее с python.org. В Windows отметьте **Add Python to PATH**. На macOS команда часто называется `python3`, на Windows можно использовать `py`.
2. Распакуйте весь проект. Не переносите один скрипт отдельно: рядом нужны папки `scripts` и `backend`. Устанавливать библиотеки для этой задачи не требуется.
3. Скопируйте исходный `лиды.csv` в удобную приватную папку. Не открывайте и не пересохраняйте исходник через Excel перед первым запуском: он может поменять телефоны и даты.
4. Откройте терминал в папке проекта: Windows — адресная строка Проводника, введите `cmd`; macOS/Linux — откройте Терминал и перейдите командой `cd` в распакованную папку.
5. Запустите команду (замените путь к файлу на ваш; кавычки нужны для путей с пробелами):

```bash
python scripts/analyze_leads.py "/путь/к/лиды.csv" --out "artifacts"
```

В Windows можно написать:

```powershell
py scripts/analyze_leads.py "C:\Users\ВашеИмя\Downloads\лиды.csv" --out "artifacts"
```

6. В терминале появится сводка. В папке `artifacts` будут:

- `leads-summary.txt` — читаемый отчёт: день и семь дней.
- `leads-report.json` — полный результат, исходные значения, замечания, альтернативы.
- `leads-normalized.csv` — все записи с нормализованными полями и замечаниями. Телефоны в экспорте защищены ведущим апострофом от выполнения как формулы в таблицах.

Это выходные результаты для чтения, а не новый исходный CSV: у нормализованного экспорта другая схема. Для повторного анализа передавайте исходный пятиколоночный CSV.

Формат: UTF-8, разделитель запятая, заголовок `дата,имя,телефон,источник,бюджет`; до 2 МБ и 10 000 записей. Дата — `19.10.2026` или `2026-10-19`. Поле с запятой заключайте в двойные кавычки. День определяется по файлу, а не по сегодняшней дате компьютера.

Если команда `python` не найдена, попробуйте `python3` или `py`. Сообщение об ошибке CSV объясняет, что исправить в новой копии выгрузки; исходник не меняйте молча. При ошибке скрипт завершится кодом 2, при успехе — 0.

В присланных материалах эталон: за 19 октября 2026 — 3 записи, средний бюджет 8 000 000 ₽; за 13–19 октября — 8 записей, средний 6 916 666,67 ₽. Нули учтены, пропуски исключены. Альтернативы описаны в AUDIT.md и самом JSON.

Все результаты содержат приватные CRM-данные. Не загружайте `artifacts` и исходники в публичный GitHub и не пересылайте без разрешения.
