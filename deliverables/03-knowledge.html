ПО МОТИВАМ ФРАГМЕНТА ЛЕКЦИИ

Что модель знает.
Что помнит.
Что нужно проверить.

Три уточнения к лекции и один полезный каркас промпта. Контекст, память и интернет — разные механизмы.

01

Контекст — не память между чатами

В лекции: «Контекстное окно — это сколько чат помнит между разными чатами».

Точнее: контекстное окно ограничивает объём информации, который модель может учитывать при обработке запроса. Оно не означает автоматического переноса сведений в новый чат.

Если вчера вы рассказали Claude про бизнес, сегодня не стоит считать эти сведения доступными без проверки: межчатовая память — отдельная функция продукта, зависящая от настроек и доступности.

02

Свежие цены требуют свежих источников

В лекции: «У Claude вообще нет доступа к интернету».

Это слишком категорично: у Claude есть инструменты веб-поиска. Доступ к ним зависит от продукта и конфигурации. Без доступного и использованного поиска нельзя рассчитывать на актуальные цены.

Практический вывод: проверяйте, выполнен ли поиск, и смотрите на дату и источник результата. Ответ модели сам по себе не подтверждает свежесть цены.

03 / Полезный каркас из лекции

Сначала сформулируйте запрос

Роль → задача → формат → пример

Это удобная структура, а не обязательный закон для каждого запроса. Лекция не содержит готового примера промпта; новый пример здесь намеренно не добавлен.

Проверено по первоисточнику. Официальный SDK Anthropic содержит инструмент web_search и пример его подключения. В описании messages история передаётся в запросе. Это подтверждает наличие веб-поиска в API, но не доступность функций в любом аккаунте Claude. Рекомендация проверять свежесть — методический вывод.

Проверенные источники: Anthropic SDK / web_search.py · Messages API (версия bcd55fe, 20.10.2026).
Страницы сайта Anthropic о контексте и памяти вернули 403; настройки конкретного аккаунта не проверены. Исходник: «лекция.txt». Все ситуации взяты только из него.
